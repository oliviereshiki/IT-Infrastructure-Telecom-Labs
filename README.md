
# IT Infrastructure & Telecom Labs

## About this project

This repository documents my hands-on technical laboratories
in IT infrastructure, networking, telecommunications,
system administration and cybersecurity.

As a qualified telecommunications technician (Swiss ES/HF)
and Apple Certified Support Professional, I am refreshing
and expanding my technical skills through practical
laboratories and professional troubleshooting scenarios.


## Objectives

- Strengthen networking and telecommunications skills.
- Develop practical IT infrastructure competencies.
- Strengthen system and network administration skills.
- Develop virtualization and cybersecurity competencies.
- Improve troubleshooting and incident management.
- Develop scripting and automation skills.
- Document technical configurations and procedures.
- Prepare for IT Support Level 1 and Level 2 positions.
- Prepare for System, Network and IT Infrastructure Administrator roles.
